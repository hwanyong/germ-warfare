# 에셋 카탈로그 (germ-warfare)
> AI/개발 참고용 에셋 레퍼런스. 이미지 재분석 없이 이 문서로 에셋을 골라 쓴다.
> 전 에셋 1회 비전 분석(2026-07 세대) 기반. 특히 **cartography 는 유사 건물도 미묘하게 다르므로** 구별점(★) 컬럼을 볼 것.

## 세계관/용도
우주인(세균 유닛)이 지구 인간 마을을 침공해 영역을 다투는 Ataxx 영토전.
- **cartography** = 배경 인간 마을 오브젝트. 셀 아래 마을/건물이 있으면 공격·파괴 연출(에셋 스왑/이펙트)에 사용. 불규칙 배치로 배경 밋밋함 제거 + 세계관 연출.
- **crosshair** = 2종: 상호작용 소스 셀 선택 표시 + 마우스 hover 포커스(룰: 소스 셀 먼저 → 빈 칸 선택).
- **cursor** = 다양한 상호작용 피드백. **characters** = 우주인 유닛(그린 p1/핑크 p2).

## 폴더
```
public/assets/
  cartography/   마을 배경 아이콘 (86, +_spritesheet.xml)
  characters 계열: cell-*.png, ship/, laser/, mascot/, dome-*.png
  crosshair/     셀 선택 + hover
  cursor/        커서 피드백(6)
  frame/         손그림 border-image (thin/circle/square/arrow)
  ui/            uipack.svg (Kenney UI 벡터)
  textures: paper.jpg
```
> 코드 배선 중인 활성 에셋: cell-green/pink, ship/ship-p1·p2, laser/beam-p1·p2·burst, frame/thin·circle·square, cursor/pointer3D·hand, crosshair/aim-move·clone, paper. 나머지는 라이브러리(P0에서 배경/이펙트로 사용 예정).
