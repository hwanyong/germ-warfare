# ADR-002 — 로비 대신 메뉴

- 상태: 승인
- 관련: [[ADR-001-fully-client-side-pve]]

## 맥락

Helldyinger의 로비는 네트워크 멀티플레이 허브(매치메이킹·존 목록·세션 핸드오프)다.
솔로 PvE에는 매치메이킹 상대가 없다.

## 결정

로비를 **메뉴 화면**으로 축소: `[게임 시작]`, `[스테이지 선택]`(진행해온 스테이지),
`[설정]`. 단, 씬 부팅 패턴(sceneId → Scene)은 유지해 나중 버튼 추가가 라우트 하나로 끝나게 한다.

## 결과

- ✅ 불필요한 로비/세션/매치메이킹 인프라 제거.
- ✅ 메뉴가 곧 미래 확장점(앱2에서 상점/대전 버튼 추가는 순수 가산).
- 스테이지 진행은 localStorage에 저장(ADR-006 원장 규율).
