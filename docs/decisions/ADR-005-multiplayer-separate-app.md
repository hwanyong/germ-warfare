# ADR-005 — 멀티플레이는 별도 앱

- 상태: 승인
- 관련: [[ADR-003-flat-single-app-repo]], [[ADR-006-anticheat-scope]]

## 맥락

사업 모델(멀티플레이 대전 + 스킨 상점)이 예정돼 있다. 이걸 이 데모 코드베이스에
"진화"시켜 넣을지, 별도로 재개발할지가 이 repo의 미래대비 범위를 좌우한다.

## 결정

**멀티플레이 + 상점은 완전 별도 앱으로 재개발**한다. 이 repo는 무료 싱글 PvE 데모로
고정. 이 데모는 서버·통화·매치메이킹·복잡한 치팅방지를 **미래대비하지 않는다**.

두 앱의 유일한 연결 = **이식 자산**: 규칙 엔진(`src/game`), AI(`src/ai`), 렌더(`src/render`).
이들을 순수·클린 모듈로 유지해 앱2가 복사/재사용한다. 앱2 착수 시 공유 방식(복사 vs npm 배포)을 결정.

## 결과

- ✅ 지난 분석의 난제(모노레포·서버검증·통화 치팅방지·Firebase)가 전부 이 repo 범위 밖으로.
- ✅ 데모는 단순하게 출시, 앱2는 백지에서 최적 스택 선택(서버 권위 등).
- ⚠️ 규칙/AI/렌더를 클린 모듈로 유지하는 규율이 데모를 "막다른 길 아닌 자산생산기"로 만드는 핵심.
