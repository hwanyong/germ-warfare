# ADR-009 — 로딩 게이트 + 스프라이트시트 미도입

- 상태: 승인
- 관련: [[ADR-008-visual-identity]]

## 맥락

에셋(이미지/폰트)이 로드되기 전 게임이 시작되면 첫 렌더/첫 발사에서 크기·위치가
어긋난다(예: 우주선 offsetHeight=0). 또한 스프라이트시트(아틀라스) 제작 필요 여부를 조사 요청받음.

## 결정 1 — 로딩 게이트

부팅을 프리로드로 게이팅한다:
- `index.html`: 로딩 씬을 critical inline CSS + body 마크업으로 **모듈 로드 전 즉시** 표시(진행률 바).
- `src/loading/preload.mjs`: 매니페스트(`assets.mjs`)의 모든 이미지 + `document.fonts.ready` 를
  로드하며 진행률 콜백. `src/main.mjs boot()` 이 프리로드 완료 후 `startGame()` → 로딩 씬 페이드아웃.
- CSS 는 Vite 가 `<head>` `<link>` 로 추출(prod) → JS 이전에 로드.

## 결정 2 — 스프라이트시트 미도입 (조사 결론)

현재 에셋 = **개별 파일 26개 / 272K** (PNG/webp/jpg). 조사 결과:

- **애니메이션은 절차적(procedural)** — 세균 울렁임=SVG feTurbulence, 우주선 bob=CSS,
  레이저=CSS/WAAPI. 프레임 스프라이트시트 불필요.
- **아틀라스 패킹**: GitHub Pages는 HTTP/2(멀티플렉싱)라 26개 소형 파일의 요청 오버헤드가
  미미 → 지금 아틀라스 제작은 조기 최적화. **미도입.**
- **애니 스프라이트**: 원본 `alien_walk.webp` = 2프레임 애니메이션 webp(마스코트) — 필요 시
  webp-anim 그대로 사용(시트 불필요). 원본 Kenney cartography 는 시트(xml)였으나 개별 PNG로 분해해 사용중.
- **신규 스프라이트 아트 제작**: 게임 루프(P0)가 요구 애니를 확정한 뒤에 판단(현재 절차적으로 충분).

## 결과

- ✅ 콜드 로드 시 진행률 로딩 씬 → 에셋 준비 후 게임 시작(첫 렌더/발사 정확).
- ✅ 스프라이트시트/신규 아트 제작 보류 — 절차적 애니 + 개별 파일 유지(린).
- 재검토 트리거: 에셋 수 급증 또는 실측 로드 병목 시 build-time 아틀라스(vite plugin) 자동화.
